# 🤖 AI Expense Tracker

An AI-powered expense tracking application that allows users to record expenses using natural language.

## 🚀 Features

- Add expenses using natural language
- AI-powered expense extraction
- Automatic category detection
- Expense dashboard
- Total spending calculation
- Transaction count
- Search expenses
- Filter by category
- Edit expenses
- Delete expenses
- Spending analytics
- Category-wise spending chart

## 🛠️ Technologies

### Frontend
- React
- Vite
- Axios
- Recharts

### Backend
- Python
- FastAPI
- SQLAlchemy
- Uvicorn

### AI
- Groq API

### Database
- SQLite
